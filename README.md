# ☕ Coffee Shop Application

A full-stack Coffee Shop web application built with React, Vite, Django REST Framework, and Material UI.

## 🚀 Features
- User Registration & Authentication (JWT)
- Browse Coffee Products with Search & Filters
- Add to Cart & Checkout
- Real-time Order Tracking (WebSocket)
- Admin Dashboard (Django Admin & React Dashboard)

## 🛠️ Tech Stack
- **Frontend:** React, Vite, Material UI, React Router, React Query
- **Backend:** Django, Django REST Framework, SimpleJWT
- **Database:** PostgreSQL (Production) / SQLite (Development)
- **Deployment:** Render (Backend) / Vercel (Frontend)

## 🏃 How to Run Locally

### Backend
  ash
cd backend
pip install -r requirements.txt
python manage.py migrate
python manage.py createsuperuser
python manage.py runserver 8001
  

### Frontend
  ash
cd frontend
npm install
npm run dev
